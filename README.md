# Airlet PDF

**By Trimenor**

A fast, lightweight PDF viewer for **Windows 10 (1809 or newer) and Windows 11, x64**. Free for personal and commercial use. No account, cloud upload or telemetry.

## Download and installation

1. Open the [latest release](https://github.com/zafodtom/airlet-pdf/releases/latest).
2. Download `AirletPDF-Setup-…-x64.exe` and run the installer.
3. Follow the setup wizard. You can then choose Airlet PDF as your default PDF viewer in Windows Settings.

The installer contains the necessary components and does not require administrator rights. It is currently unsigned, so Windows may display an unknown-publisher or SmartScreen warning.

## Features

- Open PDFs from the file dialog, by dragging them into the window or by opening associated files. Password-protected PDFs are supported.
- View the whole page by default; adjust zoom, fit to width or rotate the view.
- Search, select and copy text. Copy or save a rectangular selection of the page.
- Export pages to PNG/JPG at a chosen resolution.
- Print PDFs or create a PDF from multiple images (PNG/JPG/BMP).
- Optionally move to the next or previous PDF in the same folder. Enable **Continue between files** in the toolbar or Settings; it is off after every launch.
- Switch between Czech and English in **Settings → Language** (restart required).

Text search and selection require a text layer; OCR is not included. Rotation changes the displayed/exported/printed image but does not modify the original PDF.

## Updates

Use **Settings → Updates…** to check manually for a new version. After confirmation, Airlet PDF installs the update and reopens the document. There are no automatic background checks.

## Keyboard shortcuts

| Action | Shortcut |
| --- | --- |
| Open / close PDF | Ctrl+O / Ctrl+W |
| Search / print / export | Ctrl+F / Ctrl+P / Ctrl+E |
| Previous / next page | PageUp / PageDown |
| First / last page | Ctrl+Home / Ctrl+End |
| Zoom | Ctrl+mouse wheel, Ctrl+plus / Ctrl+minus |
| Actual size / fit width / whole page | Ctrl+0 / Ctrl+1 / Ctrl+2 |
| Rotate right / left | Ctrl+R / Ctrl+Shift+R |
| Select text / rectangular crop | Alt+T / Alt+X |
| Copy / clear selection | Ctrl+C / Escape |

# Airlet PDF — česky

**Od Trimenor**

Rychlý a nenáročný prohlížeč PDF pro **Windows 10 (1809 a novější) a Windows 11, x64**. Zdarma pro osobní i komerční použití. Bez účtu, odesílání dokumentů do cloudu a telemetrie.

## Stažení a instalace

1. Otevřete [nejnovější vydání](https://github.com/zafodtom/airlet-pdf/releases/latest).
2. Stáhněte `AirletPDF-Setup-…-x64.exe` a spusťte instalátor.
3. Projděte průvodce. Airlet PDF pak můžete nastavit jako výchozí prohlížeč PDF v Nastavení Windows.

Instalátor obsahuje potřebné součásti a nevyžaduje práva správce. Zatím není digitálně podepsaný, takže Windows může zobrazit upozornění na neznámého vydavatele nebo SmartScreen.

## Funkce

- Otevírání PDF dialogem, přetažením do okna nebo přes asociace souborů. Podporovány jsou i dokumenty s heslem.
- Výchozí zobrazení celé stránky, nastavení přiblížení, přizpůsobení šířce a otočení pohledu.
- Hledání, výběr a kopírování textu. Kopírování nebo uložení obdélníkového výřezu stránky.
- Export stránek do PNG/JPG s volitelným rozlišením.
- Tisk PDF a vytvoření PDF z více obrázků (PNG/JPG/BMP).
- Volitelné přecházení mezi PDF ve stejné složce. **Pokračovat dalším souborem** zapnete na liště nebo v Nastavení; po každém spuštění je vypnuto.
- Přepnutí mezi češtinou a angličtinou v **Nastavení → Jazyk** (vyžaduje restart).

Hledání a výběr textu vyžadují textovou vrstvu PDF; OCR není součástí aplikace. Otočení mění zobrazení, export a tisk, nikoli původní PDF.

## Aktualizace

Novou verzi můžete ručně zkontrolovat přes **Nastavení → Aktualizace…**. Po potvrzení aplikace aktualizaci nainstaluje a znovu otevře dokument. Na pozadí aktualizace sama nekontroluje.
