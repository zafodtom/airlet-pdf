# Airlet PDF 0.6.4

- More reliable manual updates: if a release download fails temporarily, the updater can use GitHub's asset API and perform a bounded retry.
- Partial installers are discarded before restarting a download. Cancellation also stops pending retries.
- Errors include the HTTP status and network error code. Redirect response bodies are excluded from downloaded data.
- Releases become public only after all update files have uploaded.

Choose **Settings → Updates…** in an installed copy. If an older updater cannot download this version, run the installer over the existing installation once; the improved download handling will apply to subsequent updates.

## Česky

- Spolehlivější ruční aktualizace: při dočasném selhání stahování může aktualizátor použít GitHub API a omezený počet opakování.
- Před novým pokusem se smaže nedokončený instalátor. Zrušení ukončí také čekající opakování.
- Chybové hlášení obsahuje HTTP stav a kód síťové chyby. Těla přesměrovacích odpovědí se nepřidávají ke staženým datům.
- Vydání se zveřejní až po nahrání všech aktualizačních souborů.

V instalované aplikaci zvolte **Nastavení → Aktualizace…**. Pokud starší aktualizátor nedokáže tuto verzi stáhnout, spusťte jednou instalátor přes současnou instalaci; opravené stahování se použije při následujících aktualizacích.
