# Airlet PDF 0.6.5

This version-only maintenance release provides a newer stable update to verify the complete in-app update flow introduced in 0.6.4. Application features, PDF rendering and updater behavior are unchanged.

In installed version 0.6.4, open a PDF and choose **Settings → Updates…**. Download the update and confirm **Restart and update**. After installation, the app should reopen the document and show version **0.6.5** in **Help → About**. A subsequent update check should report that the version is current.

## Česky

Toto údržbové vydání mění pouze číslo verze a slouží k ověření celého přechodu přes aktualizátor opravený ve verzi 0.6.4. Funkce aplikace, vykreslování PDF i chování aktualizátoru zůstávají stejné.

V instalované verzi 0.6.4 otevřete PDF a zvolte **Nastavení → Aktualizace…**. Stáhněte aktualizaci a potvrďte **Restartovat a aktualizovat**. Po instalaci se má znovu otevřít dokument a **Nápověda → O aplikaci** má zobrazit verzi **0.6.5**. Další kontrola aktualizací má oznámit, že používáte aktuální verzi.
