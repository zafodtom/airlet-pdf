# Airlet PDF 0.7.0

**File → PDF from images…** now offers two output modes:

- **One combined PDF**: the existing multi-page document option.
- **Separate PDF for each image**: each selected image creates a single-page PDF in a folder you choose, preserving its base name (`photo.01.jpg` → `photo.01.pdf`).

Page size and DPI options apply to both modes. All output names are checked before the batch starts; existing PDFs and collisions such as `photo.jpg` plus `photo.png` are rejected. Each output is finalized only after its PDF is complete. If you cancel or a later image fails, completed PDFs remain saved and the app reports their count. Source images remain unchanged.

Update an installed copy through **Settings → Updates…**.

## Česky

**Soubor → PDF z obrázků…** nově nabízí dvě varianty výstupu:

- **Jedno společné PDF**: dosavadní vícestránkový dokument.
- **Samostatné PDF pro každý obrázek**: každý vybraný obrázek vytvoří jednostránkové PDF ve zvolené složce se stejným názvem (`fotka.01.jpg` → `fotka.01.pdf`).

Pro obě varianty platí nastavení velikosti stránky a DPI. Před začátkem dávky se zkontrolují všechny výstupní názvy; existující PDF i kolize typu `fotka.jpg` a `fotka.png` se odmítnou. Výstupní soubor se dokončí až po vytvoření celého PDF. Při zrušení nebo chybě dalšího obrázku zůstanou hotová PDF uložená a aplikace uvede jejich počet. Zdrojové obrázky se nemění.

Instalovanou verzi aktualizujte přes **Nastavení → Aktualizace…**.
