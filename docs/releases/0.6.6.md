# Airlet PDF 0.6.6

- Update checks now use the installer name, size and valid SHA-256 already supplied by GitHub's release metadata. A separate manifest download is only needed for legacy assets without a digest.
- Malformed digests are rejected. Installer size, SHA-256 and the native helper's second verification remain mandatory.
- Download errors identify the failed stage and the actual response host after redirects.
- Transfer-timeout aborts reported by Qt as error 5 now use the retry/fallback path. User cancellation still stops the operation.

A temporary GitHub/CDN failure can still interrupt a request. This release removes an unnecessary request rather than guaranteeing availability of the hosting service. Installed older versions need to obtain this update first; if their download fails, run the new installer over the existing installation once.

## Česky

- Kontrola aktualizace nově využije název, velikost a platný SHA-256 instalátoru už obsažené v metadatech GitHubu. Samostatný manifest se stahuje jen u starších příloh bez kontrolního součtu.
- Neplatný kontrolní součet v metadatech se odmítne. Kontrola velikosti a SHA-256 instalátoru i druhé ověření nativním pomocným programem zůstávají povinné.
- Chyba označí fázi aktualizace a skutečný server, který po přesměrování odpověděl.
- Přerušení časovým limitem, které Qt hlásí jako chybu 5, nově využije opakování a záložní cestu. Zrušení uživatelem přenos stále zastaví.

Dočasný výpadek GitHubu/CDN může požadavek stále přerušit. Toto vydání odstraňuje zbytečný požadavek, nezaručuje dostupnost služby. Starší nainstalovaná verze musí tuto opravu nejprve získat; pokud její stažení selže, spusťte jednou nový instalátor přes současnou instalaci.
