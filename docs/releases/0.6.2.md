# Airlet PDF 0.6.2

This maintenance release introduces the **Trimenor** developer brand in the About dialog and Windows installer metadata. The user README has also been revised in English and Czech, and release files have been updated to version 0.6.2.

There are no changes to PDF rendering, document functions or performance.

To update an installed copy, use **Settings → Updates…**. The Windows installer remains unsigned and may trigger a SmartScreen warning.

## Česky

Toto údržbové vydání sjednocuje označení vývojáře **Trimenor** v dialogu O aplikaci a v údajích instalátoru Windows. Upraveno bylo také uživatelské README v angličtině a češtině a soubory vydání mají verzi 0.6.2.

Vykreslování PDF, funkce programu ani výkon se nemění.

Pro aktualizaci instalované verze použijte **Nastavení → Aktualizace…**. Instalátor zatím není digitálně podepsaný a Windows může zobrazit upozornění SmartScreen.
