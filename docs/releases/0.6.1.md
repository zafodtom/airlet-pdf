# Airlet PDF 0.6.1

- Every PDF opens in whole-page view. Toolbar buttons show the active view mode.
- Continue between files is available both on the toolbar and in Settings, with synchronized state. It remains disabled at startup.
- User-focused README in English followed by Czech; simplified About dialog with project and license links.
- Airlet PDF's own code is licensed under MIT, allowing personal and commercial use. Third-party licenses, notices, and corresponding Qt sources remain included.

To update an installed 0.6.0 copy, choose **Settings → Updates…**. Confirm the download and restart; the app installs the update and reopens the document. This release remains unsigned.

## Česky

- Každé PDF se otevře v režimu celé stránky. Aktivní režim zobrazení je označený na liště.
- Pokračovat dalším souborem je na liště i v Nastavení, se společným stavem. Při spuštění zůstává vypnuté.
- Uživatelské README anglicky a česky, stručné O aplikaci s odkazy na projekt a licence.
- Vlastní kód aplikace pod licencí MIT pro osobní i komerční použití; licence knihoven, oznámení a odpovídající zdroje Qt zůstávají součástí balíčku.

V instalované verzi 0.6.0 zvolte **Nastavení → Aktualizace…** a potvrďte stažení a restart. Aplikace nainstaluje aktualizaci a znovu otevře dokument. Toto vydání zatím není digitálně podepsané.
